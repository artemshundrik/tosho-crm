Модальне вікно. Тінь `shadow-elevated-lg` — тінь у системі має ЛИШЕ те, що спливає над сторінкою.

Складові: `DialogTrigger`, `DialogContent`, `DialogHeader`, `DialogTitle`, `DialogDescription`, `DialogFooter`, `DialogClose`.

`DialogContent` приймає `isDirty` — тоді закриття кліком повз питає підтвердження; `dismissible` навпаки прибирає це питання для переглядів, де втрачати нема чого.
