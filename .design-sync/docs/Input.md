Однорядкове поле. Розмір — пропом `controlSize`: `sm` (h-8) | `md` (h-9) | `lg` (h-10, типовий). Саме `controlSize`, а не `size`: у `<input>` `size` — нативний числовий атрибут.

Помилку показуй через `aria-invalid`, а не клас: атрибут одночасно повідомляє читача з екрана. Зазвичай не сам по собі, а всередині `FormField`.
