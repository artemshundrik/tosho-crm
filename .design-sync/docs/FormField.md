Обгортка поля: підпис, зірочка обов'язковості, текст помилки або підказки — і зв'язування їх з полем через `id` та `aria-describedby`.

`children` приймає або елемент (пропси домішуються самі), або функцію `({ id, invalid, fieldProps }) => …` — другий варіант потрібен для Radix-контролів на кшталт `Select`.
